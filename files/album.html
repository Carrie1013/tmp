INTERCEPT · 03:39

Something is blinking in the dark.

A light on the far wall, flashing on and off in a pattern. Long, short, long. It keeps repeating. It is only three letters — and if you know whose signature this is, you will not need to count them twice.

Their crown. Of course it is you who'd recognise it first.
INTERCEPT · SECOND SIGNAL

The light changes.

Now it is longer — five letters this time. Same rules. This one is not a name. It is a place. It is telling you where to go.

An album. Go to the shelf where the records live.
INTERCEPT · THE NUMBERS

Which one, though?

There are a lot of records on that shelf. The last part of the signal isn't flashes — it's a line of numbers, the kind you'd hum. But these aren't meant to be sung. Each number is a letter: 1 = A, 2 = B, 3 = C … right up the alphabet. Read the line and you'll have the name of the one to pull out.

1=A  2=B  3=C   …   19=S  20=T  26=Z

One little letter opens this chapter.
